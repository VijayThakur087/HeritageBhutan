HERITAGE BHUTAN ERP - GitHub Pages setup

1. Create a GitHub repository.
2. Upload every file in this folder to the repository root
   (also supabase.js and sync.js if you have them).
3. Settings > Pages > Deploy from a branch > main > / (root).
4. Open https://<username>.github.io/<repo>/ once with internet.
   Android/desktop Chrome: Install app.  iPhone Safari: Share > Add to Home Screen.
5. After a new index.html upload, change VERSION in sw.js (hb-erp-v1 -> hb-erp-v2).
6. Data lives in each device's browser. Move it between devices with
   Data & Backup > export / restore. Never commit backup files to GitHub.
